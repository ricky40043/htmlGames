# 架構設計｜實際運作：切換入口

本次以既有正式版本為基礎，保留原架構課程與人群模擬的完整頁面。第 14 章模擬頁頂部提供「架構設計」「實際運作」，目前頁以高亮及 aria-current 標示。其他章節不顯示此列。

- 架構設計：一般第 14 章網址或 mode=lesson。
- 實際運作：mode=world。
- 實際運作以 sessionStorage 保存 World、使用者、buffer、影片、上傳、Request、機器與速度。返回時暫停，不補跑離開期間，按「繼續世界」恢復。
- 架構頁保存月份、策略、拓樸、機器配置、角色位置、資料與紀錄。返回時重建呈現；未完成的教學動畫中止，可重新操作。月份事件重新連接原章節函式，已結算事件不重複結算；返回總結不重複計算挑戰次數。
- 儲存僅限同一瀏覽器分頁工作階段；關閉分頁或瀏覽器禁止儲存時不保證保留。清除瀏覽器網站資料會清除進度。

架構決策已經聯動：架構設計模式每次切換元件策略，就把 `{ componentId: optionId }` 寫進共用的 `youtube-architecture-v1`（sessionStorage），實際運作模式在建立世界時讀取並照著開機器、設定故障恢復時間與轉碼容錯。世界頂端的「套用中的架構」會列出八項決策各自在這個世界裡代表什麼，並標示哪幾項與預設不同；沒玩過架構模式時明說跑的是預設架構。改完決策回到世界後，按「同種子重新開始」套用新架構，或按「改用預設架構」清掉。

兩邊的**執行進度**仍各自保存（月份／人數／buffer／Request 不共用），這一點沒有變。

驗證：原架構開始課程後可返回第 0 月；實際運作加至 11 人、建立上傳後，來回切換的時間、人數、buffer、影片與上傳狀態一致；瀏覽器未記錄 JS 錯誤。既有 13 項模型測試通過。
