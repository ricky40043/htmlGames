# 架構設計｜實際運作：切換入口

本次以既有正式版本為基礎，保留原架構課程與人群模擬的完整頁面。第 14 章模擬頁頂部提供「架構設計」「實際運作」，目前頁以高亮及 aria-current 標示。其他章節不顯示此列。

- 架構設計：一般第 14 章網址或 mode=lesson。
- 實際運作：mode=world。
- 實際運作以 sessionStorage 保存 World、使用者、buffer、影片、上傳、Request、機器與速度。返回時暫停，不補跑離開期間，按「繼續世界」恢復。
- 架構頁保存月份、策略、拓樸、機器配置、角色位置、資料與紀錄。返回時重建呈現；未完成的教學動畫中止，可重新操作。月份事件重新連接原章節函式，已結算事件不重複結算；返回總結不重複計算挑戰次數。
- 儲存僅限同一瀏覽器分頁工作階段；關閉分頁或瀏覽器禁止儲存時不保證保留。清除瀏覽器網站資料會清除進度。

架構決策已經聯動：架構設計模式每次切換元件策略，就把 `{ componentId: optionId }` 寫進共用的 `youtube-architecture-v1`（sessionStorage），實際運作模式在建立世界時讀取並照著開機器、設定故障恢復時間與轉碼容錯。世界頂端的「套用中的架構」會列出八項決策各自在這個世界裡代表什麼，並標示哪幾項與預設不同；沒玩過架構模式時明說跑的是預設架構。改完決策回到世界後，按「同種子重新開始」套用新架構，或按「改用預設架構」清掉。

兩邊的**執行進度**仍各自保存（月份／人數／buffer／Request 不共用），這一點沒有變。

## 架構拓樸圖：弱網、斷線與跨區接手（2026-09-18）

這裡是 `system-design-simulator.js` 的架構設計播放器，與 `youtube-world.js` 的固定步長世界分開。修正未更動世界模型與六項架構聯動契約。

- 機器球一律用來關閉／恢復該台；上方策略文字才切換方案。未建置的 CDN 可以點球建置。「無備援」仍表示有一台運作；調整策略不會偷偷恢復先前關掉的機器。
- 弱訊號區限制的是最後一哩：此教材以固定 0.4 Mbps 示範，CDN 與回源都受限制。每個動畫步驟依當下網路條件累計傳送量，所以把弱區拖到觀眾上，正在飛的同一顆球也會變慢。既有緩衝先消耗、耗盡後才轉圈；收到較小片段並實際播放時才改變畫質。離開弱區後繼續傳完同一片段。
- 所有請求路徑節點都檢查健康狀態，包含單台 Load Balancer、CDN、儲存、快取與資料庫。機器關閉、移除或策略取消節點時，原球在目前位置標紅停留 1.2 秒；不會算作收到、補進緩衝或無聲地換成新球。先關閉又立刻恢復，也不會讓已斷的舊連線自動復活。
- 播放器以新 Request ID 重試同一片段，保留播放位置及尚未用完的緩衝。依序找同區健康服務、美國、其餘地區；CDN 不可用時可回源，觀眾仍留在原地。黃色虛線與來源文字顯示實際接手的地區，失敗路線標紅；故障機器的結構連線也會變暗。
- 共用儲存等必要後端故障時，換區不能繞過它，必須等待恢復。反之，CDN 命中的觀看沒有經過 API 或串流節點，關掉這些節點不應中斷該片段，操作紀錄會明說原因。
- 下方即時紀錄與 Request 資料列包含片段編號、嘗試次數、實際路徑、斷線原因及完成／失敗結果。手動切換來源也會留下原連線中斷紀錄。月度 QoE 評分仍由課程月份決策結算；即時弱網體驗請看播放器的頻寬、緩衝與轉圈狀態。
