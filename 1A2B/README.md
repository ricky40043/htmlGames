# 🎮 連線版 1A2B 猜數字競技場 (Multiplayer 1A2B)

一個現代化、絢麗視覺、支援多人即時連線的 1A2B 猜數字對戰遊戲。

## 🌟 遊戲亮點與特色
- **多人即時連線**：基於 Node.js + Express + Socket.IO 技術打造。
- **階段 1 (同時 1 分鐘出題)**：所有玩家同時在 60 秒內輸入 4 位不重複數字，密碼遮罩防偷看。
- **階段 2 (同時/輪流打題)**：系統自動環狀分配對手題目（每人固定猜指定對手的題目）。
- **漸進式回合限時**：
  - 第 1、2 局（回合）：每次猜題限時 **60 秒**。
  - 第 3 局開始：升級為 **90 秒**。
- **冠軍榮譽榜**：
  - 第一優先：最少猜題次數猜出 4A0B 者獲勝。
  - 第二優先：若次數相同，累積總猜題耗時最少者搶下冠軍。
- **戰況即時實況牆 (Live Feed)**：動態顯示其他對手猜出的 xAxB 戰況（隱藏具體數字，增加緊張競速拉鋸感）。

## 🚀 快速啟動指南

### 1. 安裝套件
在專案根目錄下執行：
```bash
npm install
```

### 2. 啟動伺服器
```bash
npm start
```

### 3. 開始遊玩
開啟瀏覽器訪問：
[http://localhost:3000](http://localhost:3000)
